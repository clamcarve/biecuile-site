支持的源

把配置地址、文件或分享口令丢进来，它自己认出是哪一种。

📦

TVBox 配置

jar 爬虫、采集站（JSON / XML）、多仓线路、本地 ZIP 包，OK 影视 / FongMi 的写法都认。

🐍

Python 源

内置 Python 运行环境，网上的 .py 源不用改直接导入。

📜

JS / drpy2 规则

drpy2 规则、在线 (JX) 站点，自带取页面和解析的宿主函数。

🐱

猫源

CatVod 的 Node.js 源（index.js.md5），装上运行环境就能跑。

🧭

海阔视界小程序

海阔的规则 JSON 和分享口令，规则里的 js 照原样运行，多季自动合成一部。

🐘

PHP 源 · 本地包

PHP 源、drpy-node 本地包，装上插件在本机跑。

🍥

Kazumi 规则

动漫站规则仓库，遇到验证码会让你在网页里点一下。

🗄️

Emby · Jellyfin · 飞牛

多服务器、多线路自动切换，版本 / 音轨 / 字幕都能选。

💾

网络挂载

WebDAV、SFTP、FTP 上的文件夹，按 TMDB 刮成海报墙。

📺

直播

M3U / TXT 列表，节目单、回看、多线路自动换。

🧩

组件 · 网页源

Forward / CapyPlayer 组件、自带界面的网页源和网页应用。

🧲

磁力 · 推送

磁力边下边播（插件），分享 / 推送过来的链接直接播。
