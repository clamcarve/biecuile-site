# BieCuiLe 官网

线上地址：https://tv.diaobaole.top （GitHub Pages）

## 更新版本 / 下载地址

只改 `versions.json`：

1. 在对应平台（`android` / `ios` / `pc`）的 `versions` 数组**最前面**加一条，最新的放第一个；
2. `files` 里每个文件一行：`label` 是按钮上的字，`url` 是下载地址（可以把安装包传到本仓库的 Releases，复制下载链接填进来）；
3. 提交后一两分钟网站自动更新。旧版本自动出现在“历史版本”里。

`url` 留空的按钮显示“即将开放”。
